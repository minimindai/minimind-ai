## 🛠️ Key Capabilities
- Identify missing environment variables based on stack requirements
- Enforce naming conventions (UPPER_CASE, etc.)
- Detect potential sensitive data leaks in configuration files
- Validate connection string formats (JDBC, Mongo, Postgres)
- Generate example.env files from existing configurations
