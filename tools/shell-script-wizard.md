This tool has specialized configurations for specific use cases:
- **🛡️ [Shell Script Auditor Pro](shell-script-wizard-v-auditor.md)**: Scan existing shell scripts for logic flaws, security vulnerabilities, and shell-injection risks. Get a refactored, production-ready version automatically.
- **📂 [Log Rotation & Cleanup Architect](shell-script-wizard-v-log-rotator.md)**: Design high-performance log management scripts. Handles date-stamped archiving, checksum validation, and automated cleanup with safety-first logic.
- **🚀 [CI/CD Pipeline Automation Wiz](shell-script-wizard-v-cicd-architect.md)**: Generate non-interactive, fail-hard automation scripts for Jenkins, GitLab, and GitHub Actions. Optimized for strict exit codes and environment-variable safety.
- **☸️ [Kubernetes Pod Entrypoint Guard](shell-script-wizard-v-k8s-wizard.md)**: Craft secure, PID-1 aware entrypoint scripts for Kubernetes and Docker. Handles SIGTERM traps, permission validation, and container-local path safety.
- **🔒 [Paranoid Backup & Migration Scout](shell-script-wizard-v-paranoid-backup.md)**: For high-stakes data operations. Generates scripts with forced interactive confirmation, dry-run simulation, and mandatory pre-flight checksums.
- **🔥 [Shell Injection & Security Guard](shell-script-wizard-v-injection-scanner.md)**: Specialized in identifying and fixing shell-injection vulnerabilities. Hardens Bash and Zsh scripts against malicious input and privilege escalation.
- **🔗 [POSIX Portability & Compliance Pro](shell-script-wizard-v-posix-checker.md)**: Ensure your scripts run on every Unix-like system. Detects 'Bashisms' and converts them into strictly portable POSIX-compliant syntax for generic /bin/sh.
- **☁️ [Cloud Infrastructure CLI Automator](shell-script-wizard-v-cloud-automator.md)**: Automate AWS, GCP, and Azure CLI operations with safety guards. Handles credential safety, resource verification, and idempotency for cloud management.
- **⚙️ [Systemd Service Architecture Kit](shell-script-wizard-v-systemd-gen.md)**: Design robust system services. Generates not just the shell logic, but the accompanying .service and .timer files for modern Linux service management.
- **⏲️ [Cron Job Safety Robustifier](shell-script-wizard-v-cron-robustifier.md)**: Convert flaky cron jobs into production-grade tasks. Adds absolute PATH safety, TTY checks, detailed logging, and lock file prevention for overlapping runs.
