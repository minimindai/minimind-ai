## 🛠️ Key Capabilities
- Extract keywords from PDF, DOCX, TXT, and MD documents
- Analyze keyword frequency and semantic density
- Identify search intent (Informational, Commercial, etc.)
- Categorize keywords by type (Primary, Long-tail)
- Export results as Interactive Table or CSV
- Sort and filter keywords by frequency
