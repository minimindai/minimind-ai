# 🌐 Translator

Translate text between various languages.

## 🚀 Try It Now
Experience this tool with full interactive features directly on MiniMind AI:
👉 **[Run Translator on MiniMind AI](https://www.minimindai.com/tools/translator)**

## 🛠️ Key Capabilities
- Translate documents (PDF, DOCX, MD)
- Domain-specific terminology (Business, Academic)
- Adjustable tone (Formal to Casual)
- Auto-language detection engine
- Supports 50+ global languages
- Preserves Markdown and formatting

## 💡 Example Prompts
- "Translate this technical manual into German with a formal tone."
- "Convert this business email into professional French."
- "Translate this creative story into Spanish with an informal tone."
