Create professional resumes with AI. Upload your current resume or start from scratch.

## 🛠️ Key Capabilities
- Build professional resumes from your data
- Upload existing resumes for AI enhancement
- Support cleaner formatting for common job application systems
- Summarize work history and skills
- Generate compelling professional summaries
- Export to clean, modern PDF formats

## 💡 Example Prompts
- "Build a modern resume for a Senior DevOps Engineer role focusing on AWS and Terraform."
- "Tailor my current CV for a Creative Director position at a global design agency."
- "Generate an executive summary and project highlights for a Project Manager resume."
