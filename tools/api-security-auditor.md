## 🚀 Specialized Variations
This tool has specialized configurations for specific use cases:
- **🔍 [API Security Scanner](api-security-auditor-v-scanner.md)**: Fast static analysis for identifying common API vulnerabilities and security gaps. Quick surface-level check for the most obvious security flaws.
- **🛡️ [OWASP API Security Auditor](api-security-auditor-v-owasp.md)**: Deep-dive analysis specifically mapped to the OWASP API Security Top 10 (2023). Comprehensive security review based on the industry-standard framework.
- **🔓 [BOLA Analyzer (API1:2023)](api-security-auditor-v-bola.md)**: Specialized scanner for Broken Object-Level Authorization and predictable ID flaws. Identify risks where users can access data they don't own by manipulating IDs.
- **📡 [API Threat Analysis](api-security-auditor-v-threat.md)**: Context-aware threat evaluation for public and internal enterprise endpoints. Analyze the specific threat environment and data sensitivity to determine risk likelihood.
- **💧 [Data Leakage Scanner](api-security-auditor-v-leak.md)**: Scans API responses for accidental PII, password hashes, and internal metadata leaks. Detect sensitive information exposure in API payloads.
- **🔑 [JWT & OAuth Security Audit](api-security-auditor-v-auth.md)**: Deep authentication flaw scanner for modern token-based auth mechanisms. Audit JWT and OAuth2 flows for implementation errors and bypasses.
- **📜 [NIST & PCI-DSS Auditor](api-security-auditor-v-compliance.md)**: Enterprise compliance validation for NIST SP 800-53 and PCI-DSS standards. Audit API specs for industry-specific security requirements.
- **📊 [API Risk Scorer](api-security-auditor-v-risk-score.md)**: Exploitability and impact scoring for identified API endpoints. Get a numerical risk score based on data sensitivity and threat environment.
- **🧪 [Security PoC Generator](api-security-auditor-v-poc.md)**: Generate safe, text-only proof-of-concept patterns to verify findings. Educational examples for security testing and validation.
- **🚫 [Broken Auth & ACL Checker](api-security-auditor-v-broken-auth.md)**: Identifies missing authentication and broken access control logic in APIs. Deep dive into authorization bypass and privilege escalation risks.
