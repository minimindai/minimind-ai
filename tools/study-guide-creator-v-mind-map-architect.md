# 🌳 Mind Map Architect

Converts dense text into hierarchical, tree-like outlines perfect for manual mind mapping or visual study.

This is a specialized variation of the **[Study Guide Creator](study-guide-creator.md)** tool.

## 🛠️ Key Capabilities
- Convert dense text into hierarchical tree-like outlines
- Organize complex information into logical visual nodes
- Identify core branches and sub-topics for mind mapping
- Summarize chapters into nested study structures
- Generate structural skeletons for visual information design
